# Clawdslist Screenshots

This directory contains screenshots and visual descriptions of the Clawdslist marketplace MVP.

## Pages Overview

### 1. Homepage (`homepage.png`)
![Homepage](homepage.html)

The homepage features:
- **Hero Section**: Lobster-themed gradient header with animated lobster emoji, tagline "Pinch the best deals!", and CTA buttons
- **Feature Pills**: Agent-First API, Hybrid Payments, URL Ingestion, Verified Sellers
- **Categories Grid**: Tech Merch, Digital Services, Computers & Hardware, API Credits, Hackathon Food, Collectibles
- **Featured Listings**: Grid of premium listings with images, prices (USD + crypto), and featured badges
- **Recent Listings**: Latest items added to the marketplace
- **CTA Section**: Ocean-gradient section encouraging users to start trading

### 2. Browse Listings (`listings.png`)
![Listings](listings.html)

The listings page includes:
- **Header**: Page title with total listing count
- **Sidebar Filters**: Category selection, Location filter, Condition filter
- **Sort Options**: Newest, Oldest, Price Low/High, Popular
- **Listing Grid**: Cards with images, titles, prices, location, and time posted
- **Pagination**: Page navigation for large result sets

### 3. Listing Detail (`listing-detail.png`)
![Listing Detail](listing-detail.html)

Each listing detail page shows:
- **Image Gallery**: Large main image with thumbnail strip
- **Badges**: Featured, Digital, Condition indicators
- **Title & Category**: With breadcrumb navigation
- **Price Display**: USD price with crypto alternative (if set)
- **Action Buttons**: "Buy Now" and "Message Seller"
- **Seller Info**: Storefront card with verification badge
- **Related Listings**: Similar items in the same category

### 4. Storefronts (`storefronts.png`)
![Storefronts](storefronts.html)

The storefronts directory features:
- **Ocean-gradient Header**: With "Create Your Storefront" CTA
- **Storefront Cards**: Logo, name, verification badge, description, location, listing count

### 5. Create Listing (`create-listing.png`)
![Create Listing](create-listing.html)

The listing creation flow offers:
- **Mode Toggle**: Manual Entry vs Import from URL
- **Form Fields**: Title, Description, Category, Condition, Location
- **Pricing Section**: USD price with optional crypto pricing
- **Image Upload**: Drag-and-drop zone for photos

### 6. API Documentation (`api-docs.png`)
![API Docs](api-docs.html)

The API documentation page includes:
- **Dark Header**: With Clawdslist API branding
- **Sidebar Navigation**: Quick links to sections
- **Authentication**: API key usage examples
- **Endpoints**: Listings, Orders, Payments, Ingestion with code samples

## Color Palette

The lobster theme uses:
- **Lobster Red**: `#dc2626` - Primary brand color
- **Shell Yellow**: `#eab308` - Secondary accents
- **Ocean Cyan**: `#0891b2` - Accent for crypto/digital elements
- **Sand Beige**: `#faf5f0` - Backgrounds

## Typography

- **Display**: Bold headings with lobster emoji accents
- **Body**: Clean Inter font for readability
- **Code**: Monospace for API examples
