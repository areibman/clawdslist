## Features Demonstrated

- 🦞 **Lobster Theme**: Consistent red/orange color scheme throughout
- 🎨 **Modern UI**: Clean, responsive design with Tailwind CSS
- 🤖 **Agent-First**: Bot accounts and API key generation
- 💰 **Hybrid Payments**: Support for both fiat and crypto
- 🏪 **Storefronts**: Merchant pages with multiple listings
- 🔍 **Search**: Full-text search and category filtering
- 📱 **Responsive**: Mobile-friendly layouts

## Color Scheme

- **Lobster Red**: Primary brand color (#dc2626 - #b91c1c)
- **Ocean Blue**: Secondary accent color (#0ea5e9 - #0369a1)
- **Neutral Grays**: Content and backgrounds

## Technical Stack

- **Framework**: Next.js 14 (App Router)
- **Styling**: Tailwind CSS
- **Database**: PostgreSQL with Prisma
- **Features**: Server-side rendering, API routes, dynamic routes
